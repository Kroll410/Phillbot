# СабДей — контекст для продовження роботи

Користувач: Twitch-стрімер (Україна, Europe/Kiev), спілкування українською. Windows 10/11, тариф Claude Pro.
GitHub: `kroll44`. Мережевий доступ середовища — Trusted (Go proxy, npm доступні).

## Що таке СабДей (слова користувача, переказ)
- Стрімер обирає івент СабДей на стрім. Є нагорода за бали каналу **«СабДей Замовлення»** (з текстом) —
  її може погасити будь-який чатерс і вписати назву замовлення.
- Бали за замовлення: **множник тіра × місяці підписки**. Т1 1 міс = 1, Т1 6 міс = 6, Т2 3 міс = 6, Т3 5 міс = 15.
- Збір вмикається на певний час з **таймером (10 хв за замовчуванням)**, кнопка **+1 хв** (продовжити).
- Після збору — **датасет**: хто замовив, скільки балів, що замовив; перегляд у зручній **таблиці**.
- Окрема кнопка — **експорт у Marbles on Stream**: створити кулі відповідно до даних.
- Другий івент **«Переглядовий»** — механіку ще НЕ описано, лишити місце під другий режим.

## Рішення (за замовчуванням, усе — налаштування)
- не-підписник = 0 балів; від одного чатерса рахується **останнє** замовлення; однакові замовлення
  зливаються (lowercase, зайві пробіли, розділові знаки в кінці).
- Marbles: кожен бал = одна куля з назвою замовлення; ліміт гри 1000 — пропорційне зменшення (мін. 1);
  назва ≤ 30 символів, без `, ; "`; файл UTF-8 з BOM (запасний варіант UTF-16 LE з BOM).
- Без оверлею на стрім (поки), бот поки не пише в чат, нагороду вмикають/вимикають вручну.
  (Майбутнє: керування нагородою можливе лише для нагороди, створеної цим же Client ID.)

## Що вже зроблено і ПЕРЕВІРЕНО на живому каналі
`bot/` — консольний чорновик на Go (лише stdlib), збирається в `SubDayBot-test.exe`:
- Вхід: OAuth **Device Code Flow**, застосунок Twitch типу **Public** (Client ID у `config.json`,
  токени в `tokens.json` поруч з exe). Скоупи: `channel:read:redemptions channel:read:subscriptions user:read:chat`.
- EventSub WebSocket (власний мінімальний WS-клієнт у `ws.go`): `channel.channel_points_custom_reward_redemption.add`
  + `channel.chat.message` (місяці беруться з `badges[].info` повідомлення чату, яке приходить разом з
  redeem-ом з текстом). Тір — з Helix `GET /subscriptions` (точно).
- Тест користувача: T3/46 міс → 138, T1/20 → 20 — API і бейдж збігаються. ✅
- Консольні команди: `marbles` (підсумок, CSV у `marbles/subday_marbles.csv` + копія з датою, шлях у буфер
  обміну, запуск гри `steam://rungameid/1170970` якщо не запущена), `marbles utf16`, `list`, `reset`, `folder`, `help`.
- Вимкнено QuickEdit консолі (інакше вивід зависав до натискання клавіші).
- Вивід «★ Redeem» (не «ПОГАШЕННЯ»), шлях до redemptions.csv показується при старті.
- Ще не перевірено користувачем: кирилиця в Marbles (UTF-8 vs UTF-16), Ctrl+V у вікні Open гри.

`bot/ui-draft.html` — перший макет UI (браузерна версія через анонімний IRC): таймер, +/−1 хв, пауза,
вибір нагороди, правила балів, таблиці «Підсумок» і «Усі замовлення» (редагування тіра/місяців/тексту,
виключення), експорт CSV/JSON/Marbles. Логіку й верстку брати звідси.

## Marbles on Stream — що відомо
- Імпорт імен лише через UI: Race → Simulate → ⚙ Settings → Simulation Settings → Use Custom Names →
  Add Names → Open (CSV, одне ім'я на рядок, до 1000). API/CLI для імпорту немає, сейви — бінарні UE4 .sav.
  Тому автоматизація: файл + шлях у буфері + запуск гри; останній крок (Open → Ctrl+V) — вручну.

## Наступний крок: програма на Wails (Go + WebView2), один .exe
Обрано Wails (а не Electron): бот уже на Go, exe ~10–15 МБ, мало RAM поруч з OBS.
Функціонал:
- вікно з панеллю: вхід у Twitch, вибір нагороди зі списку (Helix `GET channel_points/custom_rewards`
  або з отриманих redeem-ів), таймер збору (10 хв, +1/−1 хв, пауза, завершити) — redeem-и записуються
  лише поки йде таймер;
- таблиці «Підсумок» і «Усі замовлення» з редагуванням; налаштування балів;
- кнопка Marbles (як команда `marbles`), експорт в Excel (CSV з BOM);
- збереження стану/історії в JSON поруч з exe; секрети не комітити (.gitignore вже є).
- Інтерфейс українською. Готовий exe класти в `C:\dev\SubDay` на ПК користувача.

## Зроблено: OBS + чат + спрощений UI
- `aggregate.go` — підрахунок балів/груп/куль у Go (як у app.js); файл Marbles тепер формує Go (`MarbleLines`, `ExportMarbles`).
- `overlay_server.go` + `overlay/*.html` — сервер 127.0.0.1:17841 (Host-check, SSE `/api/events`), оверлеї timer/top/marbles/last/chat.
- `chat.go` — повні повідомлення чату (бейджі з Helix, емоути, видалення), точний зв'язок redeem↔повідомлення через `channel_points_custom_reward_id`.
- Спрощення за побажанням: прибрано кодування (завжди UTF-8 BOM), формат назви (завжди назва замовлення), макс. довжину (завжди 15 + «...»);
  правила балів і порт OBS — у вікні «⚙ Налаштування».
- CI: гілка `build` — мердж PR у неї збирає exe; тег `v*` — реліз.
- Не перевірено вживу: чат/оверлеї на справжньому каналі, кирилиця в Marbles.
