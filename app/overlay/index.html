СабДей — оверлеї для OBS

OBS → Джерела → «+» → Браузер → вставити URL, задати ширину/висоту. Фон прозорий. Параметри дописуються через ?, напр. ?scale=1.5&theme=box.

ОверлейURLРозмірПараметри
Таймер збору/overlay/timer600×220title, hideIdle=0 (показувати завжди), finishedFor=15, orders=0
Топ замовлень/overlay/top520×420limit=5, users=1, title, hideEmpty=0
Кулі / замовлення / бали/overlay/marbles620×80hideEmpty=0
Алерт нового замовлення/overlay/last800×180duration=8
Чат/overlay/chat420×700limit=40, fade=30, hide=nightbot,streamelements, size=18, badges=0, time=1
Чат (вікно)/overlay/chat?window=1—темний фон, прокрутка; також як OBS Custom Browser Dock

Спільні: scale (розмір), theme=shadow|box|plain, align=left|center|right, color=9147ff (акцент).
