Правила балів

Бали = множник тіра × місяці підписки. Тір і місяці зчитуються з бейджа в чаті; їх можна виправити прямо в таблиці.

Експорт у Marbles on Stream

—
Як завантажити в гру
Race → Simulate → ⚙ Settings (праворуч унизу) → Simulation Settings → увімкнути Use Custom Names → Add Names → Open → вибрати цей .csv. Потім запустити Bots-гонку з кількістю куль, що дорівнює кількості рядків. Кожен бал = одна куля з назвою замовлення, тож у замовлення з більшою кількістю балів більше шансів.
