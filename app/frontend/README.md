# PhillBot — правила інтерфейсу

Короткий довідник, щоб кожен новий текст, кнопка чи вікно виглядали так само, як уже наявні.
Стилі: `dist/style.css` (програма) і `../overlay/overlay.css` (оверлеї OBS).

## Шрифти

Ніколи не вказуйте назву шрифту напряму (`font-family: Arial`, `"Segoe UI"` тощо) — лише змінні:

| Змінна | Шрифт | Де використовувати |
|---|---|---|
| `--font-ui` | Segoe UI Variable Text | увесь звичайний текст, кнопки, поля, таблиці, підписи |
| `--font-display` | Segoe UI Variable Display | великі числа й заголовки: таймери, статистика, назва гри, вітання |
| `--font-mono` | Cascadia Mono | коди, URL, шляхи, журнал (`<code>` отримує його автоматично) |
| `--font-twitch` | Roobert → **Inter** (вбудований) | усе, що імітує Twitch: плитки нагород за бали каналу |

- Segoe UI Variable і Cascadia є в Windows 11. Inter вбудовано в програму (`dist/fonts/`, ліцензія SIL OFL — `fonts/Inter-OFL.txt`).
  Roobert — комерційний шрифт Twitch, його не вбудовуємо; він спрацює лише якщо встановлений у системі.
- `button`, `input`, `select`, `option` успадковують шрифт — окремо задавати не треба.
- Цифри, що змінюються (таймери, бали), — з `font-variant-numeric: tabular-nums`, щоб не «стрибали».
- Заголовки карток: `font: 600 11px var(--font-ui)`, великі літери, `letter-spacing: 1.2px`, колір `--muted`.

Приклад:

```css
.newthing{ font: 600 14px/1.4 var(--font-ui); }
.newthing b{ font: 700 28px/1 var(--font-display); font-variant-numeric: tabular-nums; }
```

## Кольори

Лише змінні з `:root`: `--bg`, `--panel`, `--panel2`, `--line`, `--text`, `--muted`, `--accent` (фіолетовий Twitch),
`--accent2`, `--ok` (зелений), `--warn`, `--bad`.

## Завантаження — єдиний підхід

Будь-яке завантаження показується **анімованою рамкою** елемента: градієнт **зелений → фіолетовий** біжить по контуру
(вікно, картка, панель). Кнопка-іконка, що запустила завантаження, при цьому крутиться.

```js
// один елемент або кілька; клас знімається сам, навіть якщо сталася помилка
await withLoading($("someModal").querySelector(".box"), () => call("SomeGoMethod"));
await withLoading([box, $("refreshBtn")], loadSomething);
```

CSS — клас `.is-loading` (у `style.css`, розділ «індикатор завантаження»). Не додавайте окремих спінерів чи інших індикаторів.

## Вікна (модалки)

- Розмітка: `<div class="modal" id="…"><div class="box settings">…</div></div>`, відкриття — `openModal(id)`.
- Закриваються кнопкою з `data-close="id"`, клавішею **Esc** або кліком поза вікном — це працює для всіх автоматично.
- Підтвердження — `await confirmBox(текст, "Так", "Скасувати")`.

## Інше

- Емодзі в інтерфейсі не використовуємо — лише SVG-іконки (як шестерня, око, кошик, оновлення).
- Ніки глядачів — завжди через `userTag(...)` (бейджі + колір ніку з Twitch).
- Мова інтерфейсу — українська.
